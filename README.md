# BOSS 1 – Electro Mechanical website

Live site: https://boss1electromechanic-au.com

Static website (HTML, CSS, JavaScript) plus `contact.php` for the Contact form email, hosted on Hostinger web hosting (Apache/LiteSpeed + PHP).

## Deployment
Hostinger hPanel → **Advanced → Git → Connect with GitHub** → this repository, branch `main`, deploy directory `public_html`.
Every push to `main` deploys automatically. The repository root is the website root.

## Notes
- `.htaccess` handles clean URLs (`/services` → `services.html`), HTTPS, redirects from the old Shopify links, and blocks hidden files.
- `contact.php` emails booking requests; set `FROM_EMAIL` to a mailbox on the domain.
- Pages are generated by a build script kept in the owner's local project (`tools/build_site2.py`). If you edit HTML here directly, let the owner know so changes aren't overwritten by a rebuild.
